## Tertin

[Tertin](https://www.tertin.com/) is an AI presentation maker by NerfedLab. Create a slide deck with AI, refine slides on a canvas, and export to PowerPoint or PDF.

[See how Tertin works](https://www.tertin.com/about).

[Follow a complete presentation example](https://www.tertin.com/guides/create-ai-presentation), with the exact prompt, editing steps, slide previews and the original PowerPoint and PDF downloads.
